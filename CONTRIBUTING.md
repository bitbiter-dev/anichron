# Contributing

Anichron is a solo project until further notice, so outside pull requests are not accepted. A pull request will be closed unmerged, however good it is.

Bug reports are welcome. Open an [issue](https://github.com/bitbiter-dev/anichron/issues) with what you did, what you expected and what happened instead. Please don't follow it with a fix.

The project is licensed under [AGPL-3.0](LICENSE), so you are free to fork it.
